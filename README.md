# E-commerce - Tênis e Sneakers Online

Uma interface moderna e responsiva de e-commerce focada na venda de calçados (tênis e sneakers). O projeto utiliza HTML5 e CSS3 com uma arquitetura modular para facilitar a manutenção e escalabilidade.

## 🚀 Tecnologias

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização avançada com o uso de Flexbox, Grid e Variáveis CSS.
- **Google Fonts**: Integração da fonte 'Ubuntu' para uma tipografia moderna.
- **SVG**: Ícones leves e escaláveis para uma melhor performance.

## 📦 Arquitetura de Estilos

O projeto utiliza uma abordagem de CSS modular, organizada da seguinte forma:

- `reset.css`: Normalização de estilos padrão dos navegadores.
- `variables.css`: Definição de tokens de design (fontes, cores, etc).
- `base.css`: Estilos globais para elementos base e utilitários (botões, containers).
- `layout.css`: Estrutura principal da página.
- `components/`: Estilos específicos e isolados para cada parte da interface:
  - `header.css`: Navegação e menu mobile.
  - `hero.css`: Banner principal e chamadas de ação.
  - `product-category.css`: Grade de categorias de estilos.
  - `product-grid.css`: Exposição de produtos e destaques.
  - `footer.css`: Rodapé, newsletter e redes sociais.

## ✨ Funcionalidades

- **Design Responsivo**: Adaptado para dispositivos móveis e desktop.
- **Menu Mobile**: Sistema de menu hambúrguer interativo (CSS-only).
- **Categorias Diversificadas**: Seções para estilos Casual, Esporte, Moderno e Futurista.
- **Destaque de Produto**: Seção Hero dedicada ao modelo "Krypton One".
- **Interface Intuitiva**: Navegação organizada por gênero e coleções (Outlet).
- **Newsletter e Redes Sociais**: Seção de engajamento no rodapé.
